# Fernanda Prieto

Premium personal brand website for psychology-informed image consulting, executive presence, and personal transformation.

## Stack

- Astro
- React islands
- TypeScript
- Zustand for justified shared state
- GSAP, ScrollTrigger, Lenis, and Framer Motion for isolated motion work
- pnpm

## Commands

```bash
pnpm install
pnpm dev
pnpm check
pnpm lint
pnpm build
pnpm format:check
```

## Repository Structure

```text
src/
  animations/
  components/
  constants/
  content/
  hooks/
  layouts/
  lib/
  pages/
  stores/
  styles/
  types/

public/

```

Architecture, product, business, design, workflow, and ADR documentation lives in `docs/` and `ai/`.
