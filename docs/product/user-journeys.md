# User Journeys

## Purpose

This document defines the core visitor journeys the website must support so information architecture, calls to action, and conversion paths remain intentional.

## Initial Content

## Individual Journey

Primary path:

1. Discover Fernanda Prieto.
2. Understand psychology and image.
3. Explore individual services.
4. Build trust.
5. Inquire through the configured contact channel.
6. Arrange a session through the response process.

This is the primary conversion journey for individuals seeking personal image consulting, primarily women around ages 30–50. It should make image consulting feel developmental, personal, and credible. Corporate services are not currently offered.

### Interim conversion path

Until Calendly is available, the homepage hero CTA opens a WhatsApp conversation
with a prefilled inquiry message. Other individual CTAs continue to open a
pre-addressed email to `contacto@fernandaprieto.cl` with a service-specific
subject. The visitor's chosen contact channel confirms the handoff; the
completed inquiry is confirmed through the normal response process.

## Brand Discovery Journey

Primary path:

1. Discover Fernanda Prieto.
2. Learn about image psychology.
3. Follow social channels.
4. Save contact information.
5. Return later as a qualified lead.

The brand discovery journey should support visitors who are interested but not ready to inquire or book.

## Journey Design Requirements

Every journey should include:

* A clear explanation of the core belief.
* A trust-building moment.
* A service exploration path.
* A next action appropriate to visitor intent.
