# User Journeys

## Purpose

This document defines the core visitor journeys the website must support so information architecture, calls to action, and conversion paths remain intentional.

## Initial Content

## Corporate Journey

Primary path:

1. Discover Fefi Prieto.
2. Understand image psychology.
3. Learn the methodology.
4. Explore corporate services.
5. Build trust.
6. Submit an inquiry.
7. Begin a sales conversation.

The corporate journey should reduce perceived risk and make the business value of executive presence clear.

## Individual Journey

Primary path:

1. Discover Fefi Prieto.
2. Understand psychology and image.
3. Explore individual services.
4. Build trust.
5. Book a consultation through Calendly.

The individual journey should make image consulting feel developmental, personal, and credible.

## Brand Discovery Journey

Primary path:

1. Discover Fefi Prieto.
2. Learn about image psychology.
3. Follow social channels.
4. Save contact information.
5. Return later as a qualified lead.

The brand discovery journey should support visitors who are interested but not ready to inquire or book.

## Journey Design Requirements

Every journey should include:

* A clear explanation of the core belief.
* A trust-building moment.
* A service exploration path.
* A next action appropriate to visitor intent.
