# Architecture Decisions

## Purpose

This directory stores architecture decision records for choices that have lasting technical, product, or operational impact.

## Initial Content

## When to Add a Decision Record

Add an ADR when choosing:

* Frameworks.
* Hosting.
* Analytics.
* Form handling.
* Calendly integration approach.
* Animation architecture.
* Content management strategy.
* Major third-party services.

## Suggested ADR Format

```markdown
# ADR-000: Decision Title

## Status

Proposed | Accepted | Superseded

## Context

What problem or decision is being addressed?

## Decision

What was decided?

## Consequences

What tradeoffs, constraints, or follow-up work result from this decision?
```
