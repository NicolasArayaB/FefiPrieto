# Visual Direction

## Purpose

This document defines the initial visual direction for the website without inventing a complete brand system before assets and identity decisions are available.

## Initial Content

## Desired Experience

The website should feel premium, editorial, psychological, and transformational.

It should not feel like:

* A fashion e-commerce website.
* A generic coaching website.
* A motivational content platform.
* A standard corporate consulting site.
* A trend-focused fashion publication.

## Visual Qualities

The visual system should emphasize:

* Strong typography.
* Generous spacing.
* Clear hierarchy.
* Refined composition.
* Purposeful motion.
* High-quality imagery or visual assets.
* Calm confidence rather than decorative excess.

## Editorial Character

The site should use storytelling, sequencing, and composition to create authority. It should feel like a thoughtful premium editorial experience that explains a serious psychological and professional concept.

## Typography

Typography is the primary driver of hierarchy. Canela is reserved for editorial emphasis—hero titles, section headlines, and reflective statements—while Inter supports all reading and interface content. Use the semantic styles and reading-rhythm rules in [typography-system.md](typography-system.md); components should not introduce local typography values.

## Spacing and Layout

Whitespace is structural, not leftover space. Use the semantic rhythm and layout primitives in [spacing-layout-system.md](spacing-layout-system.md) to establish hierarchy, reading comfort, and editorial pacing. Components may make intentional compositional exceptions—such as asymmetry, overlaps, and full-bleed media—but should draw their spacing and measures from that system.

## Motion Direction

Motion should support:

* Revealing ideas progressively.
* Connecting sections into a coherent narrative.
* Emphasizing hierarchy.
* Creating emotional resonance without reducing performance.

Motion should not exist only because the technology stack supports it.

## Imagery Direction

Imagery should support the themes of identity, confidence, professional presence, and transformation.

Avoid imagery that makes the brand feel like a generic fashion service, retail catalog, or stock business website.

## Color System

The visual language uses a neutral-first palette: warm off-whites and stone tones create the background and surface hierarchy, while deep charcoal establishes typographic authority. A single subdued green-gray brand color is reserved for purposeful emphasis, interactive states, and focus treatment rather than decorative hierarchy.

Use semantic color tokens from [color-system.md](color-system.md). Components must consume these tokens rather than introducing literal color values. Component-specific gradients and translucent treatments belong with the component that owns them; `tokens.css` contains only reusable color primitives.
